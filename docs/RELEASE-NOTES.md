# Project OS v0.1.0-alpha.2

当一轮 AI 开发只完成局部修复时，完整产品目标容易从界面消失。本版把“整体目标”设为默认入口：每项要求关联流程、模块期望、实际开发、限定证明和差距，整体判断与一个当前行动保持可见。

本版还贯通人工核对、反馈后真实重分析、原条件接续、原件读取和正常重开。每次只读分析隔离继承 MCP，避免影响工作台操作；来源与条件变化撤下旧通过，失败与复测保留。

原 Project OS 自例已完成真实模型分析、五项限定技术条件、普通重开和实际页面核对；公开包的独立检查见 docs/VALIDATION.md。当前 Codex 0.160.0 的自动日志适配未验证，本轮采用显式手工事件；独立新手理解和陌生项目稳定准确率仍需真实使用观察。

这是 MIT 许可的本地桌面 Alpha，没有托管服务或 npm 发布。安装与操作见 README.md 和 docs/ALPHA.md。
