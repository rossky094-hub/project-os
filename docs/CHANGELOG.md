# 版本变化

## 0.1.0-alpha.2 · 2026-10-05

- 默认从完整业务目标进入，将各项目标与流程、模块期望、当前适用条件、相关开发和优先差距放在一起。
- 完整目标和整体判断保留；最近局部交付折叠查看，各入口消费同一个当前行动。
- 逐项目标与模块核对、五步阅读、反例反馈、真实重分析和相同映射的确认接续贯通。
- 固定每轮“此前”证据边界，区分旧失败和同检查实际复测；目标、来源或材料变化后撤下旧通过。
- 保留补读状态与成果归属，正常重开后继续读取；轮询和历史输入读取复用有效索引。
- 每次只读分析隔离继承 MCP；不修改全局配置，分析时仍可操作工作台。
- 导出当前工作树的已核对实现与对应回归，明确 SHA 和可移植编辑；保留 MIT、独立 setup 与锁文件。
- 当前 0.160.0 仍使用显式手工事件。独立新手效果、陌生项目稳定理解和跨版本自动活动兼容没有升级为已通过。

公开版本的安装、构建、检查和启动结果见 [VALIDATION](VALIDATION.md)。本版公开源码与文档同步更新；alpha.1 保留为历史版本。

初始公开 Alpha：本地目标工作台、来源解释、场景条件、开发轮次、有限独立验证与原案例演示。旧界面素材保存在 docs/media/alpha.1，并在 [演示说明](demo.md)注明版本。
