# 从整体目标看清这一轮

当前截图来自原 Project OS 的最终正常重开，显示完整目标、当前判断和共同下一行动。默认入口为“整体目标”。

![当前完整目标工作台](media/whole-goal-workbench.png)

从一张目标卡片开始：打开“核对目标与模块”，对照人的期望、代码职责与源码；然后看对应流程及相关开发，打开实际检查原件，最后回到整体建议。五步阅读显示目标、本轮改善、证明、剩余差距、下一行动，读者答案由本人填写。

本次实际修复是让完整目标始终可见，并在真实模型分析期间保持界面可操作。每轮完成说明与限定通过分别呈现，不将技术计数当成整体目标百分比。
